# Identidade visual – Ludo Group

## Paleta de cores
| Uso sugerido | HEX |
|---|---|
| Azul-marinho (fundo principal) | #00214d |
| Azul Ludo (destaque, degradê) | #5271ff |
| Grafite (texto escuro, fundos neutros) | #4c4c4c |
| Cinza médio (logo, detalhes) | #bfbfbf |
| Cinza claro (logo, textos sobre azul) | #d9d9d9 |
| Off-white (fundos claros, texto sobre escuro) | #fffff9 |

Degradê de marca: #5271ff (canto superior esquerdo) → #00214d → quase preto (canto inferior direito).

## Tipografia
Sem serifa geométrica (Poppins). Frases de impacto em caixa alta com letras espaçadas,
alternando peso leve e negrito (ex.: "O SEU **SUCESSO** É O NOSSO **OBJETIVO**").
